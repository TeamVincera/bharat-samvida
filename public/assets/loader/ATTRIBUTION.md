# Loading artwork and animation

Emblem: Government of India, vector from https://commons.wikimedia.org/wiki/File:Emblem_of_India.svg (original SVG retained). The interface is an independent SIH project and does not claim official endorsement.

The searching orb uses `thinking-orbs` 0.3.1's exported geometry engine from Jakub Antalik's https://github.com/Jakubantalik/Libraries.dev. MIT license retained in ORB-LICENSE.txt. The point sampling and emblem-to-globe morph are project code.

Local Noto Sans and Noto Sans Devanagari fonts are from https://github.com/notofonts/noto-fonts, licensed under the SIL Open Font License (public/fonts/OFL.txt). Noto Sans is embedded in PDF exports; the Devanagari font is retained as a source asset. Exports make no external network request.

PDF Hindi text uses Mukta Regular from the official Google Fonts repository, under the SIL Open Font License. Font: https://github.com/google/fonts/tree/main/ofl/mukta. License: `public/fonts/Mukta-OFL.txt`.
